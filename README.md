# Física I (UNED) — resúmenes de estudio

Resúmenes HTML por tema para la asignatura **Física I** (Grado en Ingeniería, UNED, código 68901016), organizados en los 3 bloques del temario: **Mecánica** (temas 1-13), **Oscilaciones y ondas** (14-16) y **Termodinámica** (17-20).

Cada tema incluye: explicación pensada para quien lo ve por primera vez (intuición → definición → ejemplo → error típico), ejercicios de examen real resueltos paso a paso y fuentes (libro + página, o examen + convocatoria) visibles en cada bloque.

Libro oficial: Young & Freedman, *Sears-Zemansky Física Universitaria con Física Moderna* (vol. 1).

Ver `CLAUDE.md` para la metodología completa (fuentes, cronograma, flujo de trabajo con subagentes).
